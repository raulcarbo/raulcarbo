Filtros de carbón activado para agua

¿Dónde comprar filtros de carbón activado para tratamiento de agua industrial?

Carbotecnia ofrece filtros de carbón activado para tratamiento de agua industrial. Se usan para decloración, remoción de olor, color, sabor, compuestos orgánicos y protección de procesos posteriores como ósmosis inversa o resinas.

¿Cuáles son las diferencias entre los filtros de carbón activado para aire y para agua?

Los filtros para agua trabajan con carbón activado granular o en bloque para remover cloro, olor, sabor y compuestos orgánicos. Los filtros para aire usan carbones activados especiales para adsorber olores, vapores orgánicos y gases. El diseño cambia por caudal, tiempo de contacto, humedad y tipo de contaminante.
